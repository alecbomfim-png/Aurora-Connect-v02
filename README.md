# Aurora Connect V04

Aplicativo web experimental de mapas, planejamento de rotas e assistência ao motorista.

A versão de desenvolvimento está em [projeto/aurora-connect-v03/](./projeto/aurora-connect-v03/).

## Branches
- `main`: linha principal preservada.
- `aurora-connect-v03`: versão anterior de desenvolvimento.
- `aurora-connect-v04`: correção do uso das coordenadas GPS como origem e acompanhamento experimental do trajeto.

## Abrir o aplicativo
Acesse [Aurora Connect V04](./projeto/aurora-connect-v03/).

Consulte o README da aplicação para recursos, limitações e instruções de teste. Esta versão ainda não oferece trânsito ao vivo nem navegação 3D e não deve ser tratada como sistema automotivo certificado.
