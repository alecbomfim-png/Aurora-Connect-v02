# Arquivamento do Aurora Connect V2

O pacote ZIP do projeto deve preservar a pasta da aplicação, documentação, protótipos e a pasta `anexos/`.

Não incluir credenciais, tokens, arquivos `.env`, dados pessoais, cache do navegador ou dependências geradas. Manter uma cópia de cada versão publicada e identificar a branch/commit de origem no nome do pacote.
